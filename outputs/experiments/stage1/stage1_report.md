## 1. 修正指标的算法（已逐类复算通过）

`manual_audit_corrected_metrics_all.csv` 的计算链条：

1. 基线混淆矩阵取自 `category_metrics_and_counts.csv`（由 test 集 9406 条预测统计）；
2. 对 `audit_verdict=标签错` 的样本，按 `corrected_label` 替换真值，**模型预测保持不变**；
3. 重算 TN/FP/FN/TP，再派生准确率、负面精确/召回/F1。

复算方式：直接从 `test_predictions.csv` + `label_fixes_test.csv` 从零重算，逐类与两份指标表比对，结果：全部一致。

## 2. 人工标注字段名（第一份 CSV）

| 字段 | 含义 | 取值 |
|---|---|---|
| `sample_id` | 唯一键 | 与 outputs/predictions/*.csv 的 sample_id 一一对应，用于精确匹配原始行 |
| `split` | 数据划分 | 该样本所属 split；502 条全部为 test |
| `audit_label` | 人工标签（5 类） | 疑似标签争议 / 语义理解错误 / 转折或反讽 / 评价对象不明确 / 其他 |
| `human_sentiment` | 人工判断的真实情感 | 正面 / 负面 / 中性；这是人读原文后的独立判断，不看模型概率 |
| `audit_verdict` | 审计结论 | 标签错 / 模型错 / 双向存疑 |
| `needs_relabel` | 是否需重标 | 是 / 否 / 待定，由 audit_verdict 直接派生 |
| `corrected_label` | 修正后标签 | 0/1；仅 audit_verdict=标签错 的行有值（246 条） |
| `label_action` | 处置动作 | flip(246) / keep(211) / undecided(45) |
| `audit_reason` | 判定依据 | 引用原文原句的自由文本说明 |

权威修正清单是 `label_fixes_test.csv`（246 行，只含 flip）。502 行审计表里另有 211 条「模型错」，不可用于改标签。

## 3. split 归属核查

- 502 条审计样本的 split 分布：{'test': 502}
- 246 条标签错修正的 split 分布：{'test': 246}
- 原文与 `test.csv` 逐字一致的条数：502/502
- 存在同文本重复记录的条数：0

**结论：246 条修正全部来自 test 集，没有一条落在 train 或 val。**
按你的要求，它们只能用于测试标签质量分析，不得进入训练数据，也不得通过改测试标签宣称模型性能提升。
