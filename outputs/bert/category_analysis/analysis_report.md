## 指标解释

- TN：真实负面，预测负面。
- FP：真实负面，预测正面。
- FN：真实正面，预测负面。
- TP：真实正面，预测正面。
- 负面召回率 = TN / (TN + FP)。
- 正面召回率 = TP / (TP + FN)。

注意：热水器等样本量较少的类别，指标可能有较大波动。
